# EcoSphere Database

## Tech Stack

- PostgreSQL

## Files

schema.sql
Creates all tables and constraints.

seed.sql
Inserts demo data.

views.sql
Reusable dashboard/report views.

queries.sql
Frequently used SQL queries.

reset.sql
Clears the database.

## Setup

Run in this order:

1. schema.sql
2. seed.sql
3. views.sql

Use queries.sql for testing.

Run reset.sql before reseeding.
